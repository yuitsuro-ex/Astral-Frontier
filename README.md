# ASTRAL FRONTIER

Первый вертикальный срез оригинальной мобильной sandbox RPG. Godot **4.6.3 stable**, GDScript, Compatibility renderer. Это начало этапа 1, не законченная RPG и не финальный арт.

## Тестовый APK

Готовая ARM64-сборка: `build/astral-frontier-debug.apk` (Android 7.0+, около 26,4 MiB). Подпись и структура APK проверены; запуск на телефоне ещё не проверен. Сборка: `./scripts/build_android.sh`. Подробности: [docs/ANDROID.md](docs/ANDROID.md).

## Запуск

Открыть `project.godot` в Godot 4.6.3 и нажать F6/F5 либо выполнить:

```sh
godot --path .
```

Новый мир использует seed 71342. Для другого нового мира: `godot --path . -- --seed=12345`. Существующее сохранение имеет приоритет; перед новым миром перенесите `frontier.save` и `frontier.save.bak` из каталога пользовательских данных в безопасное место. UI создания/выбора миров пока отсутствует.

## Управление

- Телефон: левый аналоговый джойстик; JUMP; MINE (удержание); BUILD. Касание мира задаёт прицел, кнопки справа работают с последним прицелом. Без выбранного прицела действие направлено перед персонажем. Поддерживается одновременное движение и действие разными пальцами.
- ПК: A/D или стрелки, Space, ЛКМ — добыча, ПКМ — строительство, 1–4 — выбор блока, F5 — сохранение.
- Геймпад: левый стик — движение, правый — прицел, A — прыжок, X — добыча, B — строительство. Назначения стандартные Godot; проверка на физическом контроллере ещё нужна.
- SAVE сохраняет вручную; автосохранение каждые 20 секунд, при паузе приложения и штатном закрытии. «60 / 30» переключает ограничение FPS. «− / +» меняет масштаб камеры.

Стартовый запас — 30 блоков грунта. Доступны грунт, камень, песок (пока только поддерживается данными) и эфирная руда. Четыре стека показаны в панели сверху. Размещение требует соседнего блока, запаса и свободного места вне тела игрока. Дальность действия — 80 мировых пикселей. Добыча зависит от прочности.

## Проверки

```sh
./tests/check.sh
```

Скрипт изолирует пользовательские данные в `.runtime/`. Запускает импорт, тесты моделей и игровых команд, сохранение/чтение разными процессами, синтетический бенчмарк и 300 кадров smoke-теста. Для обычной игры `.runtime/` не требуется. Подробности и границы проверки: [docs/VALIDATION.md](docs/VALIDATION.md).

## Структура

- `src/core`: реестр блоков, ограниченные стеки инвентаря, проверяемые версионированные сохранения.
- `src/world`: детерминированная генерация, чанковые массивы, журнал изменений, отображение чанков.
- `src/player`: движение, столкновения с тайловыми данными, временный оригинальный персонаж.
- `src/ui`: мультитач-джойстик.
- `src/main.gd`: связка ввода, игровых команд, камеры, HUD и загрузки чанков.
- `tests`: исполняемые тесты Godot; `docs`: архитектура, художественный стандарт, Android и результаты.

[ROADMAP.md](ROADMAP.md) описывает следующие этапы. [CHANGELOG.md](CHANGELOG.md) фиксирует реализованное.
