# ROADMAP

- [x] Godot 4.6.3 проект и запускаемая сцена.
- [x] Движение, прыжок, коллизии, камера.
- [x] Мультитач-джойстик, кнопки, клавиатура и подключения геймпада.
- [x] Seed, холмы, пещеры, рудные включения; чанковое окно и выгрузка.
- [x] Разрушение/размещение с дальностью, прочностью и списанием ресурсов.
- [x] Четыре стека, панель выбора.
- [x] Версия, checksum, temp/rename, backup, автосохранение.
- [x] Тесты генерации, инвентаря, команд, backup и отдельного процесса загрузки.
- [x] Headless-замер логики и границ UI в трёх пропорциях.
- [ ] Визуальная приёмка и замер рендеринга.
- [x] Android build-tools + export template, подписанный debug APK, проверка подписи и выравнивания.
- [ ] Установка APK, физический мультитач и pause/resume на устройстве.
- [ ] UI создания мира/seed и полноценная панель инвентаря.

Этап 1 не объявляется полностью принятым без аппаратной/визуальной проверки.

## Этап 2 — выживание

Реестр предметов/инструментов; рецепты и рабочие станции; строительство с дверями/стенами; время суток; первый противник, здоровье и бой. Проверяемый цикл: добыча → инструмент → убежище → ночь.

## Этап 3 — RPG

Характеристики, оружие, броня, навыки, подземелье и один босс: **Сторож упавшей орбиты**, древний автомат с фазами защиты и перегрева. План остальных оригинальных боссов: **Матка стеклянных корней** (джунгли), **Пастырь белого шторма** (снега), **Хор глубинных спор** (грибные пещеры), **Сердце разлома** (вулкан). Это только контентный план, боссов в коде нет.

## Этап 4 — мир

Десять биомов из ТЗ, структуры, NPC, поселения, диалоги/репутация, погода, расширение существ. Добавлять по одному законченному биому с ресурсами, существами и художественным оформлением.

## Этап 5 — космос

Корабль, ремонт, отдельные seed и сохранения планет, топливо, звёздная карта, технологии и станции.

## Этап 6 — полировка

Финальные оригинальные атласы и анимации, звуки/музыка, профилирование Android, настройки управления, accessibility, устройства с вырезами, AAB и требования Google Play. Кооператив — отдельный будущий этап, сейчас не реализован.
