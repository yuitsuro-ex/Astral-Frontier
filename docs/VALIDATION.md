## Android export — дополнительная проверка

Собран debug APK 0.1.0 для ARM64, min API 24, target API 36. `apksigner verify` подтверждает подписи v2/v3, `zipalign -c -P 16 4` проходит, `aapt dump badging` подтверждает пакет и ABI, ZIP CRC проходит. В APK нет служебного `.runtime`, keystore или тестовых сохранений. Манифест явно задаёт `gl_compatibility` для Android. Автотесты после настройки экспорта: 0 ошибок; отдельные процессы сохранения/восстановления и layout checks пройдены.

`aapt2` сообщает о неиспользуемом ресурсе themed_icon из официального Godot template: экспортёр заменяет основной adaptive icon и удаляет исходный XML, оставляя его resource-table запись. Основная иконка приложения указывает на существующий `res/mipmap-anydpi-v26/icon.xml`; подпись и обычный aapt проходят. Это предупреждение инструмента зафиксировано; визуальная проверка иконки на устройстве остаётся в приёмке. В логе экспорта встречается сообщение adb о недоступном `/home/agent/.android`; экспорт успешно завершён с кодом 0.

Android runtime и FPS не проверены: устройства и эмулятора нет. Подробности воспроизводимости — `docs/ANDROID.md`.
